NJ Remixes — Fetch Tool

run locally · generates data.json · zero quota on live site
How to use

1. Open this file locally in your browser (double-click it)
2. Click Start Fetching
3. Click Download data.json when done
4. Upload data.json + index.html to GitHub
5. Repeat once a month to catch newly uploaded remixes

Filter rules

A video is included only if its title contains newjeans or new jeans AND contains remix or edit or flip.
Official channels, Shorts (under 62s), and blocklisted content are excluded.
