Privacy Policy

Last updated: May 2025 · NewJeans Remixes Fan Library

This Privacy Policy explains how NewJeans Remixes Fan Library ("we", "the site") collects, uses, and handles information when you use our website. This site is a non-commercial fan project and is not affiliated with NewJeans, ADOR, or HYBE.

1. YouTube API Services

This site uses the YouTube Data API v3 to search for and display fan-made remix videos of NewJeans from YouTube. By using this site, you acknowledge that your use is also subject to Google's Privacy Policy at http://www.google.com/policies/privacy and the YouTube Terms of Service at https://www.youtube.com/t/terms.

2. What data we access from YouTube

This site accesses the following public YouTube data via the YouTube Data API:

  • Video title
  • Channel name
  • Video thumbnail image
  • Published date
  • View count
  • Video duration
  • Video ID (used to link to YouTube)

No private YouTube data is accessed. No user YouTube account information, watch history, likes, subscriptions, or any other personal data is accessed or collected.

3. How we use YouTube data

YouTube API data is used solely to:

  • Display video cards (thumbnail, title, channel, date, views, duration)
  • Categorize videos by genre and song
  • Allow sorting and searching of results
  • Link users directly to videos on YouTube

YouTube data is never sold, shared with third parties, used for advertising, or used for any commercial purpose.

4. Data storage and caching

This site uses your browser's localStorage to cache YouTube API data locally on your device. This cache is stored only on your own device and is never transmitted to any server. The cache expires and is refreshed periodically.

The site also loads from a static data.json file hosted on GitHub Pages. This file contains pre-fetched public YouTube video metadata. No personal data is included in this file.

This site has no backend server and does not collect, store, or transmit any user data to any external server or database.

5. Cookies and local storage

This site does not use cookies. It uses browser localStorage to store:

  • Cached YouTube video metadata (auto-expires)
  • Your sidebar open/closed preference

This data is stored entirely on your device and is never shared with or accessible by anyone else.

6. Third-party services

This site uses the following third-party services:

  • YouTube Data API v3 (Google LLC) — to search and retrieve public video metadata. Subject to Google Privacy Policy.
  • Google Fonts (Google LLC) — to load the Geist typeface. Subject to Google Privacy Policy.
  • GitHub Pages (GitHub, Inc.) — to host the site. Subject to GitHub Privacy Statement.

When you click a video to watch it, you are directed to YouTube.com which has its own privacy policy and terms of service.

7. Analytics

This site does not use any analytics tools. No usage data, page views, clicks, or behavioral data is collected or tracked.

8. Children's privacy

This site does not knowingly collect any information from children under 13. If you believe a child has provided personal information, please contact us and we will address it promptly.

9. Changes to this policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date at the top of this page.
